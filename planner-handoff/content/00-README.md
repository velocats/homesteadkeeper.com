# Homestead Keeper Planner — content

Source content for the companion planner on homesteadkeeper.com (printable PDF + web).

- **Design source of truth:** `../HOMESTEAD_PLANNER_SPEC.md`. Read it first.
- **These files are the content** (the actual copy), authored once and laid out twice
  (print-first PDF and web).
- **Voice rules (hard):** write like a human; never use em-dashes. See §0 of the spec.
- **Handoff:** Claude writes this content and a Codex prompt (plus optional HTML). Codex
  performs the website update.

## Files
- `01-seasonal-front-matter.md` — the seasonal spread (Homestead at a Glance, The Homestead
  Year, This Month, Frost-Date Worksheet). Spec §12.
- `02-template-library.md` — the ten reusable print-on-demand templates. Spec §14.
- `hubs/` — per-hub planning pages (spec §5 tiering):
  - Full pages: garden, animals, orchard, food-pantry, property-equipment, inventory,
    emergency-prep.
  - Reference pages: bees, off-grid, forestry, wildlife-pests, weather-seasons.
- `front-back/` — cover, how-to-use, glossary, take-it-further (closing).
